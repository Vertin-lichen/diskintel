================================================================
 DiskIntel 0.3.0（Rust 原生窗口 · 三视图 + 双引擎）
================================================================

一、快速开始

  1) 解压到任意目录（建议不含中文与空格的路径）
  2) 双击 DiskIntel.exe

  默认从 D:\disk-intel-data\snapshots 读取快照。改数据目录：
    · 环境变量 DISKINTEL_DATA_ROOT=D:\你的目录
    · 或启动参数：DiskIntel.exe --data-root "D:\你的目录"

二、三个核心视图（工具栏切换，Ctrl+1/2/3/4）

  检索   虚拟滚动列表，446 万条只画屏幕上的几十行；行首是彩色的类型矢量图标。
         列头「名称 / 路径 / 大小 / 修改时间」可点击排序。
         搜索框支持内联条件（可与关键词混用，空格即 AND）：
           ext:pdf            只看 PDF
           size:>10m          大于 10 MB
           after:2026-01-01   修改时间晚于该日期
           kind:file          只要文件（kind:dir 只要目录）
           path:D:\资料       限定路径范围
         顶部「来源」可选：自动（有实时索引就用）/ 实时索引 / 快照。
         双击打开、右键菜单（打开/打开目录/复制路径/去空间视图）。

  空间   第一屏「物理磁盘 / 卷」总览：每个卷一张卡片，环形图显示已用/空闲，
         附容量、快照逻辑大小、文件数；点击卡片进入该卷树图。
         树图面积 = 字节数，颜色 = 目录类别（系统/程序/文档/媒体/开发/缓存…），
         文件瓷砖用文件类型色；右侧是当前目录分层列表（大小、占比、修改时间），
         可展开子目录、面包屑返回上级、点击聚合块展开「其他 N 项」。

  对比   任选 A/B 两份快照，输出新增 / 消失 / 增长 / 缩小与净变化（按变化幅度排序）。
         两份 446 万条快照约 15-20 秒，期间界面可交互。

  快照   列出所有快照的体积/条目/创建时间/备注，显示磁盘剩余与水位；可切换当前快照。

三、双引擎（内存 vs 存储）

  · 实时索引（goz）：毫秒级（10-15 ms），需要 gozd 运行（本机已提权常驻时可直连）。
  · 快照（SQLite）：不依赖任何外部进程，适合离线取证；全表关键词扫描约 0.1-1 秒。
  「自动」模式下：引擎就绪走实时，不可用自动回落快照，状态栏如实标注。

四、快照存储优化（v4 字典化，压缩约 5 倍）

  单份 v3 快照 1.5 GB → 转成 v4 后约 290 MB（实测 5.16×，13.6 秒/份，只读转换、不改原文件）：

    DiskIntel.exe --convert-v4 "D:\disk-intel-data\snapshots\20261112-100008.sqlite" ^
                   "D:\disk-intel-data\snapshots\20261112-100008.v4.sqlite"

  v4 快照可直接被本程序打开（检索略慢，空间/对比视图更快）。
  更进一步的「基线 + 增量链」方案见 docs/研究-快照存储优化分析-*.md。

五、重建索引（需要同目录的 DiskIntelCLI.exe + goz）

  点「扫描」→ 后台执行 scan（全盘扫描约 6 秒）→ snap（建库约 85 秒），完成后自动切到新快照。
  gozd 需要管理员权限读 MFT：一次性授权见旧版说明或 tools\install-engine-bridge.ps1。

六、命令行 / AI 通道

  DiskIntel.exe --probe                 打印数据根、快照清单、建库器路径
  DiskIntel.exe --engine-probe          打印实时引擎状态与三条查询耗时
  DiskIntel.exe --shot out.png --frames 30 --view space   无头截图（视觉验收/CI）
  DiskIntel.exe --convert-v4 in out     v3 → v4 转换
  DiskIntel.exe --mcp                   MCP stdio 服务端（给 agent 调用，工具名与 Python 版一致）
  DiskIntel.exe --json search "dll"     与窗口完全同口径的 JSON 输出

七、杀毒软件误报（重要）

  本程序是自编译的 Rust 二进制，没有购买代码签名证书。卡巴斯基等可能报
  「VHO:Trojan.Win32.Scar.gen」一类通用启发式名称（gen = generic，按行为猜的）。
  处理：把解压目录加入杀软排除；若已被隔离，先从隔离区恢复再加排除。
  本版本不再调用 PowerShell / 不再创建子进程来查磁盘信息，误报概率显著降低。

八、文件清单

  DiskIntel.exe          主程序（原生窗口，单文件，约 9 MB）
  DiskIntelCLI.exe       建库器（Python 打包，仅在重建索引时被调用，可缺省）
  goz\goz.exe            MFT 查询客户端（实时索引，可缺省）
  goz\gozd.exe           MFT 索引守护（需要一次性提权授权）
  tools\                 授权与诊断脚本
  README.txt             本文件

九、数据与隐私

  · 只读打开快照，绝不修改；不联网、不上传任何数据。
  · 快照目录 D:\disk-intel-data 建议定期备份（它是唯一不可重建的历史观测）。
七、更新与卸载

  「帮助 → 检查更新…」会读取 GitHub 最新版本并给出下载页；不会自动下载或替换任何文件。
  手动更新：下载新版本安装包覆盖安装，或直接替换 DiskIntel.exe；数据目录与设置不受影响。
  卸载：设置 → 应用 → 磁盘情报系统 → 卸载，或在开始菜单里点「卸载」。
  卸载时会出现一个勾选项「同时删除快照数据」，默认不勾；勾选后才会删除数据根下 snapshots\ 里的快照。

八、快照什么时候生成

  默认只有你点「扫描」时才建快照，程序启动不会自动建。
  如果需要开机自动建，工具菜单勾选「启动时自动建快照」（同一小时内不会重复建）。
