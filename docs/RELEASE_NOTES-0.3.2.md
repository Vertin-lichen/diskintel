# DiskIntel 0.3.2

## 新增

- **Windows 安装包**：`DiskIntel-0.3.2-Setup.exe`，双击安装、开始菜单快捷方式、标准卸载；
  卸载时提供「同时删除快照数据」选项（默认不勾），避免误删历史证据。
- **检查更新**：帮助 → 检查更新…，读取 GitHub Releases 最新版本并给出下载链接（不自动安装）。
- **启动时自动建快照**（可选，默认关闭）：工具菜单勾选后，启动 3 秒后台建库；
  间隔不足 60 分钟会自动跳过，避免频繁建库。
- **低价值结果扩容**：新增「冷门」分类——不是常用文档/图片/音视频/压缩包/代码的扩展名（.d/.mui/.pdb/.etl/.dat 等）
  默认折叠；`.git` 整棵豁免；仅影响界面，MCP/JSON 输出不受影响。
- 菜单栏去掉重复的产品名与 Logo（窗口标题已显示），工具栏更紧凑。

## 改进

- 空间页：物理磁盘分组、实际占用 vs 快照逻辑口径分离（继承 0.3.1）。
- 快照页：删除（移入待删除 + MANIFEST）、备注内联编辑（继承 0.3.1）。
- Hero 检索、搜索历史、列宽拖拽（继承 0.3.1）。

## 修复

- 空间页首次打开时的磁盘探测阻塞（USB 硬盘 2.3 s 唤醒）改为异步加载。

## 已知限制

- 快照为 v3 格式时单份约 1.5 GB；可用 `--convert-v4` 转为字典化格式（约 290 MB），但 v4 的路径排序检索较慢。
- 低价值折叠在命中超过 20 万时按已加载窗口统计（折叠条 tooltip 会注明）。
- 实时引擎需要 goz 常驻进程与一次性管理员授权；未配置时自动回落快照引擎。

## 校验

- 单元测试 132 项全绿；
- 冷启动首帧、内存、检索与对比耗时见 `docs/bench-*.md`（由 `tools/bench.ps1` 采集）。
