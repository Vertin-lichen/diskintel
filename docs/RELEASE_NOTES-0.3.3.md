# DiskIntel 0.3.3

## 新增

- **托盘常驻**：关闭窗口默认最小化到托盘（可关闭），托盘菜单可显示窗口/立即建快照/检查更新/退出；方便 AI 随时调用。
- **自动快照策略**：首次运行自动建第一份；默认每 7 天至少一份；可选「每次启动建」；旧快照按保留份数自动移入待删除。
- **自定义快照目录**：安装时或设置里改到其它盘，避免 C 盘被快照占满；卸载时可一并清理（含放在其它盘的快照）。
- **折叠规则可配置**：新增「保留扩展名」「保留目录前缀」；备份/归档目录可整棵保持可见。
- 设置窗口（工具 → 设置）集中管理快照、折叠、托盘选项。

## 改进

- 低价值规则：收窄 logs 目录判定（用户自己的 D:\logs 不再被折叠）；默认保留清单加入镜像/压缩/文档等 50 项扩展名。
- 折叠审计：F 盘「系统重装备份」实测折叠率 50% → 47.5%（默认）→ 0%（加入保留前缀后）。
- 快照清理：4 份旧快照（7.95 GB）移入待删除，只保留最新一份 1.5 GB。

## 修复

- `--convert-v4` 在本机创建临时库失败的问题（先建空文件再交给 SQLite 打开）。
- 检查更新的代理超时问题（0.3.2 已修）。

## 已知限制

- v4 快照目前只有 GUI 读层支持，`--json` / MCP 仍按 v3 查询；因此默认不自动转 v4（设置里可选）。
- 安装包未签名，首次运行可能触发 SmartScreen；Release 附 SHA256。
